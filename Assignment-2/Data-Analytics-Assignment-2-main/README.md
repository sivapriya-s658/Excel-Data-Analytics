# Excel Assignment 2-Data Cleaning and Transformation

This repository contains my solution for Data Analytics Assignment 2. I handled the missing values in Price and Category, corrected the inconsistent text in Product Name and Category, removed the duplicate rows, split the Product ID into Manufacturing Date and Country Code, and merged Brand Name and Product Name into Product Brand. I then formatted Price as currency and Manufacturing Date as dd-mm-yyyy. Finally, I applied conditional formatting to the Price column and to highlight Electronics in the Category column.
